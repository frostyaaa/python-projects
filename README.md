# python-projects

# 🐍 Python Projects Collection

This repository contains beginner-to-intermediate Python projects built to practice programming concepts, problem-solving, file handling, and GUI development.

## 📂 Projects Included

### ⏰ Digital Clock
**File:** `digital_clock.py`

A Python digital clock application that displays:

- Current time
- Day
- Date
- Live updates

**Concepts Used:**
- Tkinter
- DateTime module
- GUI development

---

### 📧 Email Validation
**File:** `email_validation.py`

A simple Python program to validate email addresses using pattern matching.

**Features:**

- Checks email format validity
- Detects invalid input
- User-friendly validation output

**Concepts Used:**

- Regular Expressions (Regex)
- String handling
- Conditional statements

---

### 💰 Expense Tracker
**File:** `expense_tracker.py`

A Python application to track expenses and maintain spending records.

**Features:**

- Add expenses
- Save records
- Track expenses by date
- View spending history

**Concepts Used:**

- File handling
- CSV operations
- Functions
- Date handling

---

### 📁 File Manager

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/your-username/python-projects.git
```

Move to project directory:

```bash
cd python-projects
```

Run any file:

```bash
python digital_clock.py
```

Example:

```bash
python expense_tracker.py
```
